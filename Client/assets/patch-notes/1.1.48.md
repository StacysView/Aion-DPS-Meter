# Nouveautés de la version 1.1.48

## Panneaux par-dessus l'écran
- Les panneaux (familiers, cubes, barre d'incantation, puissance de la cible, Soins, Dégâts reçus) ne s'affichent plus quand Aion 2 n'est pas lancé. Ils reviennent tout seuls quelques secondes après le lancement du jeu.
- Nouvelle option, désactivée par défaut : les cacher aussi quand une autre fenêtre est devant le jeu (navigateur, Discord...).
- La fenêtre principale du meter reste toujours visible.
- Les deux options sont dans Paramètres > Overlay, sous « Cacher les overlays pendant les menus du jeu ».
- Comme pour les menus, il faut que « Verrouiller tous les panneaux » soit activé : un panneau déverrouillé n'est jamais caché.
