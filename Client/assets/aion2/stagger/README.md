# Stagger values

`skill_stagger.json` - skill id -> how far one hit lowers a monster's stagger bar (the game's "Groggy guard energy",
effect type GroggyGuardDecreaseEnergy in the client's skill tables), 3,329 skills of every class. From SkeeveTV's
repository (MIT, https://github.com/SkeeveTV, release 1.18.2), unchanged. Used by `Aion2StaggerTable` and
`Combat/StaggerAttribution`.
