# Pokémon du thème Monstres

`dex.json` : les 649 premiers Pokémon (id, nom fr/en, rareté 0 commun → 4 légendaire, types, évolutions). `normal/<id>.png` et `shiny/<id>.png` : sprites pixel art 96 × 96 (Noir/Blanc), tirés du dépôt de sprites de PokeAPI (github.com/PokeAPI/sprites).
